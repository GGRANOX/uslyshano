# Услышано — список изменений к уже собранному проекту

> Как использовать: вставь этот файл в тот же чат/проект в твоём AI-кодере, где уже собрано приложение (по исходному ТЗ). Это не новый проект, а список точечных правок к существующему. Пройдись по пунктам по порядку, каждый отдельным сообщением, не все разом — так проще проверять, что реально изменилось.

## Роль

Ты уже собрал(а) MVP "Стена" по моему предыдущему ТЗ. Ниже — список изменений, накопившихся после обсуждения. По каждому пункту: сначала проверь, реализовано ли это уже в текущем коде, и если да — пропусти, если нет — внеси изменение.

## 1. Переименование проекта

**Было:** "Стена" — **Стало:** "Услышано"

Замени везде в интерфейсе: заголовок в шапке, тег `<title>` в браузере/metadata, любые текстовые упоминания названия. Внутренние имена переменных/таблиц в коде трогать не обязательно, если это лишняя работа.

---

## 2. Лайки → реакция «Услышал(а)» без счётчика

**Было:** ❤ лайк с видимым числом.
**Стало:** 🫂 «Услышал(а)» — один клик на сессию на стикер, **число нигде не показывается**. Автор при просмотре своего поста видит только факт "кто-то откликнулся" (например, иконка подсвечивается/меняется), не количество. Причина: публичный счётчик превращает продукт в соревнование, что прямо противоречит тому, на чём построено позиционирование.

Если в базе есть столбец с числом лайков — либо удали, либо просто перестань его показывать в UI (можно оставить в БД, если жалко удалять миграцию, но в интерфейсе быть его не должно нигде).

---

## 3. Новая функция: «Рандомный лист» (важно — вероятно, этого ещё нет)

Кнопка (например, в шапке рядом с названием), которая открывает **один случайный** не скрытый и не истёкший стикер в отдельном сфокусированном экране/модалке — не просто скролл к случайному месту на холсте.

Внутри этого экрана:
- сама карточка стикера (тот же визуальный стиль, что и на холсте)
- кнопка «Услышал(а)»
- кнопка «Ещё один» — подгружает следующий случайный
- кнопка «Поделиться» — рендерит **именно эту карточку** в отдельную аккуратную картинку для шеринга в соцсети (не просто копирует ссылку на сайт)

Это не второстепенная фича. Это основной канал привлечения читателей — тех, кто ничего не пишет сам, а заходит посмотреть. Без обязательств, без регистрации — просто нажал и увидел чей-то момент.

Запрос к базе для MVP — просто случайная выборка одной подходящей записи, сложная оптимизация на этом масштабе не нужна.

## 4. Тексты в интерфейсе

Если сейчас там placeholder-тексты или что-то отличается — замени на эти формулировки:

| Место | Текст |
|---|---|
| Первый экран / онбординг | «Анонимно. Услышано.» |
| Расширенная версия (если есть место под заголовком) | «Пиши то, что чувствуешь — с пометкой настроения. Читай, что чувствуют другие — свои посты или случайные. Нажми «услышан(а)», если тронуло. Через неделю всё исчезнет — успей.» |
| После отправки поста | «Готово. Через неделю это исчезнет — а пока кто-то, возможно, это прочитает.» |
| Футер / экран «о проекте» | «Радость, боль, всё, что не скажешь вслух — здесь тебя услышат.» |

## 5. Монетизация: платная версия реакции

В дополнение к декорациям (если уже сделаны) — обычная «Услышал(а)» бесплатна, но можно добавить платную «тёплую» версию (более заметная/анимированная для автора), ₸100–200. Не влияет ни на какие публичные метрики.

---

## 6. Мелкое: согласие на подборку

При отправке поста — необязательный чекбокс (по умолчанию **выключен**): «Можно использовать в подборке лучших постов». Понадобится позже для еженедельной подборки в соцсетях — без явного согласия автора пост в такую подборку попадать не должен.
